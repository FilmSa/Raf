## Проверенные серверные сценарии

- Строго два поля в ответе ESP32: `access` и `status`; HTTP 200 при разрешении и отказах.
- Неизвестная карта и заблокированный профиль отклоняются без вызова распознавания.
- Несовпадение, отсутствие лица, несколько лиц, некорректный/большой файл, недоступный/неправильно отвечающий Python запрещают проход.
- Фото PNG допускается для регистрации, но не для ручки ESP32.
- Регистрация, уникальность UID, блокировка, разблокировка, удаление, сохранность имени в старых событиях.
- Административная авторизация, завершение сессии, ограничение попыток входа, проверка origin и ключа устройства.
- Блокировка карты во время распознавания отменяет успешный проход.
- При невозможности записать аудит доступ запрещается.
- Поиск ФИО с кириллицей без учёта регистра, фильтр отказов и границы московского дня вплоть до наносекунды.

## Проверка настоящего распознавания

Сквозной тест запускал два настоящих сервиса на свободных портах с отдельной временной базой. Использовались тестовые фотографии из официального репозитория OpenCV; положительный запрос содержал заново сжатый JPEG, отличающийся байтами от эталонного файла.

Подтверждены статусы `success`, `unknown_uid`, `face_mismatch`, `no_face_detected`, `multiple_faces`, `inactive_user`, `service_unavailable`. Для последнего Python действительно останавливался. После удаления профиля записи истории сохранялись.

## Проверка веб-панели

В Edge проверены вход, добавление сотрудника по фото, перевод UID в верхний регистр, тестовый проход, появление события в журнале, поиск/сброс фильтров, блокировка/разблокировка, удаление с подтверждением и выход. JavaScript-исключений и ошибок Content Security Policy не обнаружено.

Вёрстка визуально просмотрена при ширине 1440 и 390 пикселей. Горизонтальное переполнение всей страницы отсутствует; широкие таблицы имеют внутреннюю прокрутку. Скриншоты сохраняются в `.runtime` и относятся к тестовой базе.

## Ограничения проверки

- Физическая ESP32-CAM/RC522 не подключалась. Качество кадров, распиновка, Wi-Fi, светодиоды и управление замком требуют проверки на реальном устройстве.
- Это функциональная проверка модели на тестовых снимках, а не измерение вероятности ошибок или точности на вашей проходной.
- Проверка живости лица не реализована; фотография лица сама по себе не доказывает присутствие человека.
- Docker Engine на машине не запущен, поэтому сборка образов и работа контейнеров не проверены. Проверена только конфигурация Compose; локальные Go/Python работают и проверены отдельно.
- Linux/macOS-инструкции и контейнерная эксплуатация не проходили отдельный прогон на этих платформах.
- Нагрузочные испытания и аудит внешнего HTTPS-развёртывания не выполнялись.
